# Cyber-Security-threats-Analysis---PowerBI

This interactive dashboard provides a comprehensive analysis of global cybersecurity threats from **2015 to 2024**. It helps stakeholders understand the **nature, frequency, sources, and impact** of various cyberattacks across different industries.

## 🧩 Key Metrics

- **Total Incidents**: 3000
- **Users Affected**: 2 Billion
- **Total Financial Loss**: $50.49 Million
- **Top 3 Most Affected by Financial Loss**:
   - Banking
   - Government
   - IT

## 🔍 Interactive Filters

- **Country Selector**: View threats specific to a region
- **Year Range Slider**: Analyze threats over a chosen period
- **Security Vulnerabilities**: Filter based on root causes
